# User Profile Feature Implementation Plan
> **For agentic workers:** REQUIRED SUB-SKILL: Use skill `executing-plans` to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cho phép tất cả user (admin/moderator/user) chỉnh sửa thông tin cá nhân (name, birthday, note, avatar) và đổi mật khẩu qua trang `/profile`, truy cập từ dropdown avatar ở header.

**Architecture:** Mở rộng auth module (server) với 2 endpoint mới `PUT /auth/me` và `PUT /auth/me/password` — user ID luôn lấy từ JWT token. Frontend có trang `ProfilePage` với `ProfileForm` và `ChangePasswordModal`, dropdown `UserAvatarDropdown` tích hợp vào `AppTopbar`.

**Tech Stack:** Express + Zod + bcrypt (backend); Vue 3 Composition API + PrimeVue + Pinia + VeeValidate (frontend); Vitest (unit tests); Playwright (E2E)

**Spec:** [docs/profile/specs/profile-design.md](../specs/profile-design.md)

```ts
// changePasswordSchema: currentPassword required, newPassword min 8,

export const changePasswordSchema = z.object({ ... }).refine(...)
export type ChangePasswordInput = z.infer<typeof changePasswordSchema>
```

`auth.service.ts` — thêm 2 methods:
```ts
async updateProfile(userId: number, input: UpdateProfileInput): Promise<UserRow>
// UPDATE users SET name=?, birthday=?, note=?, avatar=?, updated_at=NOW() WHERE id=?
// Chỉ whitelist các field trên, không cho phép cập nhật role/email/status

async changePassword(userId: number, input: ChangePasswordInput): Promise<boolean>
// SELECT password FROM users WHERE id=?
// comparePassword(input.currentPassword, hash) → throw ServiceError 401 nếu sai
// hashPassword(input.newPassword)
// UPDATE users SET password=? WHERE id=?
```

`auth.controller.ts` — thêm 2 handlers:
```ts
async updateMe(req: Request, res: Response): Promise<void>
// userId = (req as any).user.id
// gọi authService.updateProfile(userId, req.body)
// sendSuccess(res, updatedUser)

async changeMyPassword(req: Request, res: Response): Promise<void>
// userId = (req as any).user.id
// gọi authService.changePassword(userId, req.body)
// nếu false → sendError(res, 'Current password is incorrect', 401)
// nếu true → sendSuccess(res, { message: 'Password updated successfully' })
```

`auth.routes.ts` — thêm 2 routes sau route GET /me:
```ts

import apiClient from './api.service'
import type { UpdateProfileDto, ChangePasswordDto } from '@/types/profile.types'
import type { AuthUser } from '@/types/auth.types'

export const profileService = {
  async updateProfile(data: UpdateProfileDto): Promise<AuthUser> {
    const { data: res } = await apiClient.put<{ data: AuthUser }>('/auth/me', data)
    return res.data
  },
  async changePassword(data: ChangePasswordDto): Promise<void> {
    await apiClient.put('/auth/me/password', data)
  },
}
```

`auth.store.ts` — thêm action `updateUser`:
```ts
function updateUser(updatedUser: Partial<AuthUser>): void {
  user.value = { ...user.value!, ...updatedUser }
  localStorage.setItem('user', JSON.stringify(user.value))
}
// return: thêm updateUser vào return object
```

```ts
// useProfile.ts
export function useProfile() {
  const loading = ref(false)
  const error = ref<string | null>(null)

  async function updateProfile(data: UpdateProfileDto): Promise<AuthUser>
  // loading = true → profileService.updateProfile(data) → loading = false
  // on error: set error.value, rethrow

  async function changePassword(data: ChangePasswordDto): Promise<void>
  // loading = true → profileService.changePassword(data) → loading = false
  // on error: set error.value, rethrow (let component decide UI response)

  return { loading, error, updateProfile, changePassword }
}
```
